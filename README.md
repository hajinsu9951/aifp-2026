## 수업 페이지의 기능

- **240분 시간표** — 블록을 누르면 해당 부분으로 이동하고 타이머가 자동 설정
- **활동지** — 입력 즉시 자동 저장, 구글 문서로 제출
- **확인 문제** — 즉시 채점과 해설, 새로고침해도 기록 유지
- **채점 기준표** — 요소별 상·중·하 기준과 자기 채점
- **체험 활동** — 센서 세어 보기, 네트워크 고르기 퀴즈, 편향 시뮬레이터, 반응 시간 측정, 안전거리 시뮬레이터

## 사용 방법

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 서버가 필요 없습니다.

### 구글 드라이브 제출 설정

`config.js`를 열어 제출용 구글 드라이브 폴더 링크를 넣으면 활동지에 **제출 폴더 열기** 버튼이 생깁니다.

```js
driveFolderUrl: "https://drive.google.com/drive/folders/...",
```

기본 제출 방식인 **📄 구글 문서로 만들기**는 아무 설정 없이 바로 동작합니다.
활동지 내용이 복사되고 새 구글 문서가 열리며, 학생이 붙여 넣으면 본인 드라이브에 저장됩니다.

> 참고 · `☁ 드라이브에 바로 저장` 기능은 구글 OAuth 클라이언트 ID가 필요하고 `http(s)` 주소에서만 동작합니다.
> 파일을 직접 열어 쓰는 경우에는 「구글 문서로 만들기」를 사용하세요.
