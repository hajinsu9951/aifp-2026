① 평균선으로 네 칸을 나누면 부호가 보입니다

스마트 화분 한 개를 엿새 동안 같은 시각에 잰 온도와 토양 수분입니다(설명용으로 만든 숫자). 평균선 두 개를 그으면 산점도가 네 칸으로 나뉩니다. 오른쪽 위·왼쪽 아래(Ⅰ·Ⅲ) 점은 편차의 곱이 양수, 왼쪽 위·오른쪽 아래(Ⅱ·Ⅳ) 점은 음수입니다. 점을 끌어 옮기면 표와 공분산이 바로 바뀝니다.

편차의 곱을 넓이(사각형)로 보기 손계산 모드 (곱 칸을 비워 두기)
곱 > 0 곱 < 0 곱 = 0 · 금색 점선 = 평균선 · 점을 손가락이나 마우스로 끌어 보세요
왜 ‘곱’인가 · 두 편차의 부호가 같으면(둘 다 평균보다 크거나 둘 다 작으면) 곱은 양수, 다르면 음수입니다. 곱을 모두 더하면 “같은 방향으로 움직인 점”과 “반대로 움직인 점”의 힘겨루기 결과가 남습니다. 점에서 평균선 교차점까지 그린 사각형의 넓이가 곧 그 곱의 크기입니다. 멀리 있는 점일수록 목소리가 큽니다.
공분산의 정의 (이 실습실은 모두 모집단 공식, n으로 나눕니다)
Cov(x, y) = Σ(x − x̄)(y − ȳ) ÷ n
통계 프로그램은 표본 공식(n − 1로 나눔)을 쓰기도 합니다. 공분산 값은 달라지지만, 뒤에서 만드는 상관계수 r은 어느 쪽으로 계산해도 같습니다(탭 ③에서 확인).
발문
  1. Ⅰ·Ⅲ 칸 점이 3개, Ⅱ·Ⅳ 칸 점이 3개로 같은데 공분산은 음수입니다. 개수가 아니라 무엇이 결과를 정했나요?
  2. 점 6을 끌어 평균선 교차점 가까이 옮기면 공분산이 어떻게 변하나요? 왜 그런가요?
  3. 편차를 곱하지 않고 그냥 더하면(Σ(x − x̄)) 언제나 얼마인가요? 그래서 곱이 필요합니다.

② 단위를 바꾸면 공분산은 흔들리고 r은 버팁니다

같은 화분, 같은 엿새입니다. 온도를 화씨로, 토양 수분을 소수로 바꿔 적어도 점의 모양은 그대로입니다(축 눈금만 바뀝니다). 그런데 공분산은 단위를 따라 커졌다 작아졌다 합니다. “관계의 세기”를 재는 자로는 쓸 수 없다는 뜻입니다.

온도 단위
수분 단위
규칙 한 줄 · x′ = a·x + b, y′ = c·y + d로 바꾸면
Cov(x′, y′) = a·c·Cov(x, y) · σx′ = |a|σx · σy′ = |c|σy
그래서 r′ = a·c·Cov ÷ (|a|σx · |c|σy) = ±r. 더하는 수 b, d(켈빈의 +273.15, 화씨의 +32)는 평균만 옮기고 편차를 바꾸지 못합니다.
부호가 뒤집히는 경우‘건조도 = 100 − 수분’처럼 c가 음수이면 r의 부호만 바뀌고 크기는 같습니다. “온도가 높을수록 수분이 줄어든다”와 “온도가 높을수록 건조도가 커진다”는 같은 이야기입니다. 보고서에서 변수를 어떻게 정의했는지 꼭 밝혀야 하는 이유입니다.

③ 표준화를 한 단계씩 실행하기

단위 문제를 없애는 방법은 각 값을 “평균에서 표준편차 몇 개만큼 떨어졌나”로 바꾸는 것, 곧 표준화입니다. z = (x − x̄) ÷ σ로 바꾼 뒤 곱의 평균을 내면 그것이 상관계수입니다. 단계 버튼을 눌러 계산과 그림과 코드가 함께 움직이는 것을 보세요.

표본 공식 (n − 1로 나누기)

지금 실행 중인 코드 Python · 코랩에 그대로

왜 −1 ≤ r ≤ 1 인가 · z 점수는 평균 0, (모집단 공식에서) 제곱의 평균 1입니다. 0 ≤ Σ(zx − zy)² ÷ n = 1 − 2r + 1이므로 r ≤ 1, 0 ≤ Σ(zx + zy)² ÷ n = 2 + 2r이므로 r ≥ −1. 등호는 모든 점이 한 직선 위에 있을 때뿐입니다.
n이냐 n − 1이냐 · 체크 상자를 켜면 σ가 조금 커지고 z가 조금 작아지지만, 마지막에 곱의 합을 다시 같은 수(n − 1)로 나누므로 r은 소수점 끝자리까지 같습니다. 판다스의 df.corr()와 넘파이의 np.corrcoef가 같은 r을 내는 이유입니다.
